Exposición JavaScript

Variables, valores y tipos de datos

Literales, tipos de datos, scope, coerción y referencias

1 · Declaración de variables

const, let y persona

const PI = 3.1416;
let edad = 20;
edad = 21;
const persona = { nombre: "Juan" };
persona.nombre = "Juanjo";

const no permite reasignar la variable, pero sí permite modificar propiedades de un objeto. let sí se puede reasignar.

2 · Scope de bloque

let vs var dentro de un if

if (true) {
  let enBloque = "solo vive aquí";
  var seEscapa = "var ignora el bloque";
}
console.log(seEscapa); // funciona
console.log(enBloque); // ReferenceError

let vive solo dentro del bloque { }. var tiene scope de función, no de bloque: se "escapa" del if.

3 · Tipos de datos primitivos

number, string, boolean, undefined, null, bigint, symbol

const numero = 42;
const texto = `Edad: ${edad}`;
const booleano = true;
const indefinido = undefined;
const nulo = null;
const grande = 9007199254740993n;
const simbolo = Symbol("id");

JS tiene 7 tipos primitivos. Los arreglos, objetos y funciones son del tipo object / function.

4 · Rarezas del lenguaje

typeof, arrays y precisión numérica

console.log(typeof null);        // "object" (bug histórico)
console.log(typeof NaN);         // "number"
console.log(Array.isArray([1,2,3])); // true
console.log(0.1 + 0.2 === 0.3);  // false

Los decimales se guardan en binario y eso genera pequeños errores de precisión: 0.1 + 0.2 da 0.30000000000000004.

5 · Coerción de tipos

"5" + 3 vs "5" - 3, == vs ===

console.log("5" + 3);  // "53" (concatena)
console.log("5" - 3);  // 2 (convierte a número)
console.log(5 == "5");  // true
console.log(5 === "5"); // false

== convierte tipos antes de comparar. === nunca convierte: compara valor y tipo. Por eso siempre se recomienda usar ===.

6 · Valor vs referencia

Primitivos se copian, objetos se comparten

let x = 10, y = x; y = 20;
console.log(x, y);          // 10 20

const a1 = [1, 2];
const a2 = a1; a2.push(3);
console.log(a1);            // [1, 2, 3]

const copia = [...a1]; copia.push(4);
console.log(a1, copia);     // [1,2,3] [1,2,3,4]

Números se copian por valor (independientes). Arrays/objetos se copian por referencia: a2 apunta al mismo array que a1. El spread [...a1] sí crea un array nuevo.

7 · Hoisting, TDZ y shadowing

El comportamiento oculto de var y let

console.log(mensaje); // undefined (var se iza)
var mensaje = "hola";

console.log(nombre2); // ReferenceError (TDZ)
let nombre2 = "Juan";

let nivel = "afuera";
{ let nivel = "adentro"; console.log(nivel); }
console.log(nivel); // "afuera"

var se "iza" con valor undefined. let existe pero está bloqueada (Temporal Dead Zone) hasta su línea. El shadowing permite que una variable interna tape a una externa sin pisarla.

8 · Comparaciones e igualdad

Casos raros y valores falsy

console.log([] == false);        // true
console.log(null == undefined);  // true
console.log(null === undefined); // false
console.log(NaN === NaN);        // false
console.log(Object.is(NaN, NaN));// true

console.log(Boolean(0), Boolean(""), Boolean(null),
            Boolean(undefined), Boolean(NaN)); // todos false

NaN nunca es igual a sí mismo con ===; Object.is corrige ese caso especial. Existen 6 valores "falsy" en JS: 0, "", null, undefined, NaN y false.

9 · Copia superficial vs profunda

{...spread} vs structuredClone

const original = { datos: { edad: 20 } };
const copiaSuperficial = { ...original };
copiaSuperficial.datos.edad = 99;
console.log(original.datos.edad); // 99 !!

const copiaProfunda = structuredClone(original);
copiaProfunda.datos.edad = 1;
console.log(original.datos.edad); // sigue en 99

El spread solo copia el primer nivel: lo anidado sigue siendo la misma referencia compartida. structuredClone crea una copia totalmente independiente en todos los niveles.
